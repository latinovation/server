# Plantilla de `Org/`

Copia la carpeta `Org/` a la raíz de tu baúl personal de Obsidian (`scripts/install-mcp.sh` lo ofrece automáticamente si no existe). No cambies los nombres de las carpetas: el MCP y el relay dependen de ellos.

- `CLAUDE.md`: contexto del equipo para agentes. Lo edita solo el curador.
- `canónico/`: solo el curador.
- `aportes/<tu-slug>/`: tu carpeta. Créala con tu slug (minúsculas, sin acentos).
- `_plantillas/`: en Obsidian, Ajustes → Plantillas → carpeta `Org/_plantillas`.
- `archivo/`: notas archivadas; el MCP no las indexa.
